# 초경량 개역개정 성경 뷰어

다른 부가 기능 없이 **"원하는 성경 장절을 입력하면 즉시 개역개정 본문을 보여주는"** 가장 단순하고 빠른 프로그램입니다.

---

## 실행 방법

### 방법 1. 파이썬 데스크톱 프로그램으로 실행 (권장)
- 폴더 내 **`실행.bat`** (또는 **`run.bat`**) 파일을 더블클릭합니다.
- 콘솔 검은 창 없이 성경 뷰어 창만 바로 실행됩니다.
- *(직접 실행 시: `pythonw bible.py` 또는 `python bible.py`)*

### 방법 2. 웹 브라우저로 실행
- 폴더 내 **`bible.html`** 파일을 더블클릭합니다.
- 크롬, 엣지, 웨일 등 웹 브라우저에서 즉시 열리며, 인터넷 연결 없이 완전히 오프라인으로 작동합니다.

---

## 지원하는 입력 형식

상단 검색창에 다양한 방식으로 장/절을 입력하고 **Enter**를 누르면 0.01초 만에 본문이 표시됩니다:

| 입력 예시 | 설명 |
| :--- | :--- |
| `창 1:1` 또는 `창1:1` | 창세기 1장 1절 (표준 약어) |
| `요한복음 3:16` | 요한복음 3장 16절 (전체 이름) |
| `마 5:3-10` | 마태복음 5장 3절부터 10절까지 |
| `시 23` 또는 `시편 23편` | 시편 23편 전체 (1~6절) |
| `창세기 1장 1절` | 한글 장/절 표기 |
| `롬 8:28` | 로마서 8장 28절 |

---

## 주요 특징
1. **극도의 단순함**: 검색창과 본문 표시창만 존재하는 미니멀 UI
2. **초고속 반응**: 오프라인 로컬 데이터셋으로 검색 지연시간 0초
3. **간편한 복사**: 검색 후 상단의 `[본문 복사]` 버튼 클릭 시 해당 구절이 클립보드에 바로 복사
4. **한국 성경 표준 66권 약어 완벽 지원**
